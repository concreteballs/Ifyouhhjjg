# Commercial licensing and project support

**Status:** policy proposal accompanying the draft Personal-Use License. It is
not a commercial contract or a binding price list.

## Intended access model

| Access path | Intended terms |
|---|---|
| Individual users | Free personal, educational, hobby, and non-commercial research use under the project license |
| Donations | Optional support; no additional rights or features are promised in exchange |
| Premium | Optional paid access to clearly identified additional features or hosted services |
| Premium Pro | Higher-tier optional access, capacity, support, or professional features, defined when the product is implemented |
| Commercial organizations | Separate written commercial agreement before commercial deployment or integration |

## Important boundaries

- Free personal use is not a commercial-use license.
- A donation is voluntary and does not buy a license or confer ownership.
- Premium and Premium Pro are product/service subscriptions. They do not automatically authorize commercial deployment, resale, redistribution, or sublicensing of the source code.
- Commercial agreements should identify the legal customer, permitted use, deployment scope, number of users/instances, redistribution rights, duration, support, fees, and termination terms.
- No prices, service levels, or Premium feature list are promised until published separately.

## Before public release

1. Confirm the actual copyright holder(s) for every file and whether any contributors have separate rights.
2. Have the draft license reviewed by a lawyer familiar with software licensing in the intended markets, including Spain/EU.
3. Decide the governing law, dispute venue, consumer-law wording, termination/cure process, and liability language.
4. Review all future contributions before accepting them; obtain clear rights to license contributions under the project terms.
5. Keep third-party dependencies and their notices separate from the project's own license.

The project should be described as **source-available under a custom personal-use license**, not as open source, while commercial use is restricted. The Open Source Definition does not allow an open-source license to prohibit commercial use.
